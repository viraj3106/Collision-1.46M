# COLLISION Google Colab Retraining Guide

This document outlines the step-by-step procedure for uploading real-world feedback datasets, setting up dependencies, loading frozen COLLISION model checkpoints, verifying parameter counts, and launching fine-tuning or retrain experiments on a free or paid Google Colab GPU/TPU instance.

---

## 1. Environment Setup on Colab

In a Google Colab notebook cell (`.ipynb`), select **GPU runtime** (`Runtime -> Change runtime type -> T4 GPU` or `A100 GPU`), then run:

```bash
# 1. Clone repository (or upload repository zip)
!git clone https://github.com/viraj3106/Collision-1.46M.git
%cd Collision-1.46M

# 2. Install dependencies
!pip install torch numpy matplotlib psutil
```

---

## 2. Uploading & Preparing Datasets

Upload the converted real-world dataset (`real_world_formatted.jsonl`) generated by `training/prepare_real_world_dataset.py` into Colab under `datasets/collision_instruct_v1/`.

```bash
# Run data quality & dataset preparation script directly inside Colab
!python data/clean_real_world.py
!python training/prepare_real_world_dataset.py --input-file data/real_world/cleaned/real_world_cleaned.jsonl --output-file datasets/collision_instruct_v1/real_world_formatted.jsonl
```

---

## 3. Loading Frozen COLLISION Architecture & Verifying Parameters

To load the frozen `COLLISION-10M` checkpoint and verify that the parameter count matches exactly **10,282,304**, execute:

```python
import torch
from model.config import ModelConfig
from model.transformer import CollisionTransformer

# Instantiate model architecture
config = ModelConfig()
model = CollisionTransformer(config)

# Calculate parameter count
param_count = sum(p.numel() for p in model.parameters() if p.requires_grad)
print(f"COLLISION Model Parameter Count: {param_count:,}")
assert param_count == 10282304, f"Parameter mismatch! Expected 10,282,304, got {param_count}"

# Load frozen weights
checkpoint_path = "checkpoints/phase12b/collision-3.38m-phase12b-best.pt" # or model weights checkpoint
if os.path.exists(checkpoint_path):
    state_dict = torch.load(checkpoint_path, map_location="cpu")
    model.load_state_dict(state_dict["model_state_dict"] if "model_state_dict" in state_dict else state_dict)
    print("Frozen COLLISION-10M weights loaded successfully.")
```

## 5. Saving Checkpoints & Evaluating Model Progression

During training, checkpoints are saved per epoch or best validation loss:

- Best model checkpoint saved to: `checkpoints/colab_experiment/collision-best.pt`
- Training metrics saved to: `experiments/colab_experiment/metrics.json`

### Validation Loss & Perplexity Comparison

```python
import math
import torch

def compute_perplexity(loss):
    return math.exp(loss)

# Baseline COLLISION-10M Validation Loss / PPL
baseline_val_loss = 0.746  # Validation loss of COLLISION-10M baseline
baseline_ppl = math.exp(baseline_val_loss) # 2.11 PPL

# New Colab Experiment Validation Loss / PPL
exp_val_loss = 0.695 # Example Colab checkpoint loss
exp_ppl = math.exp(exp_val_loss) # 2.00 PPL

print(f"Baseline COLLISION-10M  -> Val Loss: {baseline_val_loss:.4f} | Perplexity: {baseline_ppl:.2f}")
print(f"Colab Retrained Model   -> Val Loss: {exp_val_loss:.4f} | Perplexity: {exp_ppl:.2f}")
```
