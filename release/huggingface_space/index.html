💻 Python SDK & API Quickstart

Use the COLLISION NLP Engine in Python directly from the repository or Hugging Face Hub.

1. Complete NLP Engine Quickstart 
from collision.nlp import CollisionNLPEngine

# Initialize the NLP suite
engine = CollisionNLPEngine()

# 1. TextRank Keyphrase Extraction
res = engine.extract_keyphrases("Transformers and natural language processing revolutionize modern AI.")
print("Keyphrases:", res.keyphrases)

# 2. Topic Classification
topic = engine.classify_topic("The Federal Reserve adjusted monetary interest rates.")
print("Topic:", topic.primary_topic, topic.confidence)

# 3. Tone & Formality Analysis
tone = engine.analyze_tone("Consequently, empirical evidence supports the hypothesis.")
print("Formality:", tone.formality_score, "Sentiment:", tone.sentiment_polarity)

# 4. Proofreading & Spelling Correction
corrected = engine.proofread("The artifical inteligence model gave an amazeing answer.")
print("Corrected:", corrected.corrected_text)

# 5. Extractive Reading Comprehension
qa = engine.answer_question(
    context="COLLISION-10M has 10.28 million parameters across 12 layers.",
    question="How many parameters does the model have?"
)
print("Answer:", qa.answer)
