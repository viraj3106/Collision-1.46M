# PHASE 72 — COLLISION-10M DATA & GENERATION DIAGNOSTIC

This directory contains the strictly controlled Phase 72 diagnostic suite.

## Files:
- `phase72_diagnostic.py`: Core diagnostic functions for tokenizer analysis, dataset distribution audit, and generation benchmark.
- `run_phase72.py`: Runner script executing the full Phase 72 diagnostic workflow.
- `reports/phase72_report.md`: Markdown diagnostic report.
- `reports/phase72_metrics.json`: Machine-readable diagnostic metrics.
- `reports/phase72_generations.json`: Raw benchmark outputs across models and temperature settings.
